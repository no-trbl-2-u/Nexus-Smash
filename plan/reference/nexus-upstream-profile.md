## 7. Observability / the "UI" — CHANGED (this is the headline delta: a real local web GUI)

**The old statement "No bespoke web UI for the loop" is false upstream.** `@usenexus/cli` is a local React GUI that both *observes* and *drives* the loop.

**How it runs** (`packages/cli/bin/nexus.mjs`; `server/server.mjs:1-3`): `npx @usenexus/cli` from the repo root starts a Node `http` server on `127.0.0.1`, random port (or last launch's), a per-launch token in the URL, strict Host+Origin checks; opens the browser; one server per repo recorded in `.nexus/server.json`, a second launch opens the first (`server/instance.mjs`); `--replace` parks every session and takes over (`bin/nexus.mjs:177-205`). Sessions are hosted through `@anthropic-ai/claude-agent-sdk` `query()` on the user's Claude Code login with `settingSources: ['project']` so the repo's commands, skills and hooks load; `canUseTool` turns `AskUserQuestion` into GUI buttons and other tools into approve/deny cards; fallback `NEXUS_PROVIDER=cli` drives `claude -p` stream-json (`server/provider.mjs:1-36`). ## Architecture in one paragraph

A repo gains `skills/` (imperative Markdown verbs; `/march` → `/next` → `ship-a-chunk`), a v2 `plan/` (a shrinking roadmap of specs with acceptance IDs and S/M/L chunks, Asap/Held lanes, append-only `ARCHIVE.md`, scored AUDIT/CRITIQUE/CANDIDATES queues, `bearings.md` as law with expansion knobs), an `identity/` layer (footgun ladder + numbered decisions, both maintained by `settle`), and untracked runtime state (`claims` orphan branch, `.nexus/` ledgers, notice board, vault). Each tick `/march` sweeps vetoes and motion stalls, triages issues, then runs exactly one chunk: the lead claims it by compare-and-swap, delegates the build into a worktree, gates, closes via a pending file, and lands on main (owner) or as a PR (contributor). The cloud tick wraps the same verb in a ceiling, a shared-subscription quota governor, an idle fingerprint skip and a lost-to-background check, with a heartbeat that cancels wedged runs and alarms when the loop stops shipping. When the queue empties, generators and aged promotion behind a 3-day veto issue refill it. `@usenexus/cli` is a local React GUI over the Agent SDK that hosts star-named sessions in their own worktrees, draws them as orbs and filaments from structured beats, merges every open question into one inbox with Haiku-drafted answers, shows the plan in `/next`'s own pick order, steers terminal sessions through a PreToolUse hook, parks and resumes sessions across restarts, and keeps secret values out of the model by construction; the cloud loop in turn builds that GUI, walks its demo screens in headless Chrome, and files what it sees as audit rows.

## Five things a generic open-source harness is least likely to have (updated)

1. **A local GUI whose plan, claims and steering are all passthroughs to the repo's own scripts** — `order.mjs`/`progress.mjs`/`claims.mjs`/`announce.mjs` run as the acting session, so "the board never disagrees with /next" and a refusal is "the module's own words" (`packages/cli/server/plan.mjs:1-19`; `README.md:70-77`).
2. **The silt valve**: aged candidates auto-promote into a Held lane behind a `loop:veto` GitHub issue; closing the issue is the veto, silence builds it (`scripts/plan/promote.mjs`; `skills/expand.md §6`; `skills/march.md` Step 0).
3. **Cloud governors that spend nothing to decide not to run**: quota governor on the subscription's `seven_day` reading, idle fingerprint skip, weighted ceiling, lost-to-background mark, motion-vs-liveness heartbeat (`templates/scripts/cloud/{quota,idle,lost}.mjs`; `scripts/plan/motion.mjs`).
4. **Beat-reduced agent stage + steer-at-tool-boundary**: the UI animates only from structured beats with a pure replayable reducer, and an owner's tug interrupts a terminal session via a `PreToolUse` deny whose reason is the owner's line (`shared/beats.mjs`; `.claude/hooks/steer.mjs`; `identity/decisions/2026.md` D1).
5. **A loop that browses and audits its own GUI without being allowed to dim it**: demo-scenario walks in headless Chrome produce `walk.json` findings for `/iterate` dimension H, under a "magic guard" that forbids removing particles, colour or motion (`packages/cli/scripts/walk.mjs`; `plan/56-loop-browses-the-gui.md:113-137`).
